# Tracing the hidden feature through several false leads

I started with the largest-looking weight changes. That was the first bait. The entries sat on upstream columns that were inactive on the public data, so changing them left the prediction unchanged. I then checked which paths were actually live and followed the effect forward to the output. My next mistake was to trust raw SVD and PCA directions. They gave clean-looking axes, but they mixed ordinary model structure with the planted noise. A single sparse autoencoder run led to another dead end: the apparent feature moved when I changed the input scale or random seed. Those two failures were useful because they showed me that a plausible direction was not enough. It had to survive a causal test and repeat across runs. I trained sparse autoencoders at several scales and seeds, kept the directions that repeated, and combined the small family they formed. I used the output sensitivity to choose the sign, then fitted a small rank-one correction in the affected layer. The water balance set the size of the edit. The same repaired model and direction were written to both leaderboard halves, and the final submission reached the public score ceiling. I found a compact behavioral repair by following the live computation path, discarding several attractive false leads, and checking the remaining feature against the observed runoff. The conspicuous edits helped most by showing me where not to look.
